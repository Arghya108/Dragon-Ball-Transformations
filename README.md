# Dragon-Ball-Transformations
🐉 Dragon Ball Super — Power Beyond Gods
An interactive fan-made website featuring Goku and Vegeta with full transformation sequences from Base Form all the way to their ultimate forms. Built with pure HTML, CSS, and vanilla JavaScript — zero frameworks, zero dependencies.

✨ Features

🥊 2 Playable Characters — Goku and Vegeta, each with their own transformation chain
⚡ 7 Transformations per character — cycling serially on every button click
🌟 Smooth transition animations — screen flash, character pop-in, and fade effects
💫 Dynamic aura system — color-coded glowing rings per transformation
⚡ Electric spark particles — active on SSJ2 and SSJ3 forms
📊 Power level bar — fills up with each transformation
🔵 Form progress dots — tracks which form you're currently on
🌌 Animated star background — canvas-based twinkling stars
📱 Responsive design — works on mobile and desktop
